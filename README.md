# FormFlow — מערכת הטפסים של שווה עסקים 360

מימוש Frontend של מערכת טפסים חכמה על פי מסמך האיפיון (`איפיון_מערכת_טפסים_FormFlow.docx`)
וחבילת ה-Handoff העיצובית (`design_handoff_formflow_shaveh360`) — RTL מלא, עברית תחילה,
בצבעי המותג של מועדון שווה עסקים 360, במצב בהיר ובמצב כהה.

## הרצה

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # בדיקת טיפוסים + בילד פרודקשן
```

## מחסנית

לפי פרק 8 באיפיון: **React 19 + TypeScript** (Vite), **dnd-kit** לבונה הגרירה,
**Recharts** לגרפים, **lucide-react** לאייקונים, **react-router** לניווט.
אין Backend בשלב זה — הנתונים הם Mock בזיכרון עם התמדה ל-localStorage
(טיוטת הבונה וטיוטת הממלא בטופס הציבורי); TanStack Query ישולב עם חיבור ה-API.

## מסכים

| מסך | Route | פונקציונליות |
|---|---|---|
| 01 · ריכוז טפסים | `/` | חיפוש, סינון לפי סטטוס, טבלת טפסים, פעולות מהירות |
| 02 · בונה טפסים | `/form/conf-2026/build` | גרירת שדות מהספרייה, שינוי סדר, בחירת שדה ועריכת הגדרות/ולידציות, Undo/Redo (Ctrl+Z/Y, עד 50 צעדים), Autosave עם חיווי, תצוגת דסקטופ/מובייל |
| 03 · דשבורד תשובות | `/form/conf-2026/responses` | כרטיסי KPI, גרף קו (יום/שבוע/חודש), דונאט, עמודות; טבלת תשובות עם חיפוש וסינון; סימולציית "עדכון חי" — שורה חדשה נכנסת עם הבהוב; ייצוא CSV המכבד את הסינון |
| 04 · לוגיקה מותנית | `/form/conf-2026/logic` | כרטיסי כללים אם/אז, הפעלה/כיבוי, הוספה/שכפול/מחיקה, פאנל פעולות זמינות |
| 05 · התראות מייל ו-SMS | `/form/conf-2026/settings` | טוגלים חיים, תצוגה מקדימה חיה של המייל עם משתני מיזוג, ניהול נמענים, מונה תווים ומקטעי SMS, לוג שליחות |
| 06 · עיצוב ומיתוג | `/form/conf-2026/design` | ערכות נושא, בורר צבעים חי, פונטים (Rubik/Heebo/Assistant/Open Sans), מצב כהה לטופס, תצוגה מקדימה חיה |
| 07 · טופס ציבורי | `/f/product-conf-2026` | 3 שלבים עם פס התקדמות, ולידציה בזמן אמת ביציאה משדה (מייל/טלפון/ת"ז כולל ספרת ביקורת), גלילה לשגיאה הראשונה, שמירת טיוטה לממלא, רספונסיבי מלא, מצב בהיר/כהה; שליחה מוסיפה שורה לדשבורד |
| 08 · מצב כהה | כל ממשק הניהול | מיפוי מלא לטוקני ה-dark מה-handoff, החלפה מהטופבר |

## טוקני עיצוב

מוגדרים ב-`src/styles/tokens.css` כ-CSS Custom Properties (בהיר + `[data-theme='dark']`),
אחד-לאחד מטבלאות הצבעים ב-README של חבילת העיצוב: navy `#12265A`, royal `#0D4EF2`,
sky `#A9CBF1`, lime `#D9F051`, magenta `#EE2BC3` וכו'. טיפוגרפיה: Rubik לכותרות
ומספרים, Assistant לטקסט רץ (Google Fonts).

## הערות

- הלוגו הוא Placeholder וקטורי (`src/components/LogoMark.tsx`) — יש להחליף בקובצי ה-SVG
  הרשמיים של המותג בכל המופעים (טופבר, טופס ציבורי, תבנית מייל, פוטר).
- האייקונים הוחלפו מאימוג׳י לספריית Lucide בקווי מתאר, כנדרש ב-handoff.
- נגישות: ניווט מקלדת (כולל גרירה חלופית בלחיצה בבונה), `aria-describedby` לשגיאות,
  `role=switch/radiogroup` לרכיבים, ניגודיות לפי ההנחיות (טקסט navy על lime).
